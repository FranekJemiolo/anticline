Anticline Quant Terminal v1.0.0

Offline-first visual client and analytical workbench for the Orogen lakehouse.

Architectural Pillars

  • Cross-Origin Isolation: Embedded coi-serviceworker injecting COOP/COEP for multithreaded WASM and SharedArrayBuffer memory buffers.
  • Zero-Copy Data Bridge: Direct Arrow vector sharing between DuckDB worker and main UI thread without serialization bottlenecks.
  • Delta-Append Dual-Store: Blends historical OPFS cold partitions with live in-memory streaming hot buffers, auto-flushing at 50,000 ticks.
  • Visual ASOF Join Builder: Drag-and-drop temporal joins aligning macroeconomic indicators with intraday trade series.
  • P2P CRDT Multiplayer: Yjs mesh syncing collaborative overlays, trendlines, and viewport anchors.
  • NAT Traversal Settings: STUN/TURN fallback diagnostics alerting users when symmetric NAT blocks peer swarms.
  • Encrypted Module Vault: Zero-knowledge AES-GCM (256-bit) credential storage in IndexedDB protecting proprietary API keys (e.g. FRED) at rest.
  • 18 Multi-Asset Ingestion Connectors: Real-time streaming and batch ingestion covering Macro, Equities, Fixed Income, FX, Commodities, Crypto, Fundamentals, Sentiment, Alternative, Satellite, and News feeds.
